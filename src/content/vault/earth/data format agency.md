- primary limitation of data portability is the lack of format options on import or export
- often little choice in data formats with online platforms but more choice with offline software
- decreasing agency with more cloud-based and/or [[proprietary data export is shallow|proprietary formats]]
- exerting control over capture methods through software design
- some designs allow arbitrary datatypes / filetypes, some allow a subset, some allow only [[proprietary data export is shallow|proprietary]], some allow only widely used standards
- export as, save as
- backups / syncs that aren't portable due to data format - or significant increase on capacity / productivity through using a certain format over another (eg Outlook exports can be generic or specialised if you plan to import back into Outlook)
- what are the ethics of restricting expression into particular formats?
