- RDF came from MCF from Apple, serialised using XML,
- RDF came from data to web
- Microformats came from web to data
- Microformats don't need a separate web page for machines to read, but have limited datatypes as they work by convention 
- RDFa is microformat style with RDF flexibility
- RDFa is RDF encoded in HTML (adds a few attributes to it)
- Minimises redundancy between machine-readable and human-readable data (like microformats)
